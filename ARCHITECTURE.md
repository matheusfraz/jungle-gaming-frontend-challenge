# Architecture

## Current foundation

- `src/routes` owns navigation and URL validation. Route components stay thin and delegate domain work to `src/features`.
- Each `src/features/<domain>` is organized into `api`, `components`, `hooks`, and `pages`; shared UI primitives, layout, feedback, and hooks have separate top-level locations.
- `src/routeTree.gen.ts` is generated by the TanStack Router Vite plugin and must not be edited by hand. Only the root and home routes are currently implemented; the authenticated route directory is reserved for protected routes.
- `src/contracts` is the source of truth for shared request/response schemas and inferred types.
- `src/lib/http` and `src/lib/query` centralize REST transport and cache policy.
- `src/mocks` is the only application boundary that imports MSW. Mock mode is opt-in through `VITE_ENABLE_MOCKS`.
- `src/realtime` is reserved for versioned Socket.IO events and REST reconciliation once the server contract is defined.
- `src/features` is reserved for catalog, NFT detail, favorites, cart, checkout, orders, auth, profile, and wallets.
- The required runtime and test tools are declared in `package.json`; `components.json` configures shadcn/ui generation, while generated primitives belong in `src/components/ui`.

## Contracts and state

Money is represented as a decimal string in API contracts; calculations belong in `src/lib/money.ts`. URL state (search, filters, ordering, and pagination) is validated at the route boundary. Server state belongs in TanStack Query. Session, cart persistence, optimistic updates, and order state transitions are not implemented yet because their product and API contracts have not been supplied.

## REST and realtime

REST is the source of truth for reads and reconciliation. Socket.IO messages must identify the resource and its monotonically increasing version; handlers should reject stale or duplicate versions and invalidate/refetch the corresponding query after reconnect. No socket connection or event schema is enabled until the backend contract exists.
